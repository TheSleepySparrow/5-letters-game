# Quasar App (quasar-5-letters)

Голововоломка \"Пять букв\" по мотивам игры от Тинькофф

## О приложении

Это кроссплатформенное приложение, построенное на Vue 3 и Quasar Framework, которое работает как веб-приложение в браузере и как нативное мобильное приложение на Android. Один и тот же код используется для обеих платформ благодаря технологии Capacitor.

## Что такое Capacitor?

**Capacitor** - это современная платформа для создания кроссплатформенных мобильных приложений, разработанная командой Ionic. Она позволяет:

- **Использовать один код** для веб и мобильных платформ (iOS, Android)
- **Обернуть веб-приложение** в нативный контейнер, создавая полноценное мобильное приложение
- **Доступ к нативным API** через JavaScript (камера, файловая система, уведомления и т.д.)
- **Простое развертывание** - веб-версия работает как обычный сайт, мобильная версия компилируется в APK/IPA

### Как это работает?

1. **Веб-версия**: Приложение работает как обычный Vue.js SPA (Single Page Application) в браузере
2. **Мобильная версия**: Capacitor оборачивает скомпилированное веб-приложение в нативный Android контейнер
3. **Один код**: Вся бизнес-логика, компоненты и стили одинаковы для обеих платформ
4. **Нативные возможности**: При необходимости можно добавить доступ к нативным функциям устройства через Capacitor Plugins

### Структура проекта

```
src/                    # Исходный код приложения (Vue компоненты, логика)
src-capacitor/          # Конфигурация Capacitor для мобильной платформы
  android/              # Android-специфичные файлы и нативная конфигурация
```

При сборке:
- **Веб**: `quasar build` создает оптимизированные файлы в `dist/spa/`
- **Android**: Capacitor копирует файлы из `dist/spa/` в `src-capacitor/android/` и создает нативное приложение

## Установка зависимостей

```bash
npm install
# или
yarn install
```

## Разработка

### Запуск в режиме разработки (веб)

```bash
npm run dev
# или
quasar dev
```

Приложение откроется в браузере с hot-reload (автоматическая перезагрузка при изменениях).

### Линтинг кода

```bash
npm run lint
# или
yarn lint
```

### Тестирование

```bash
npm test              # Запустить тесты один раз
npm run test:watch    # Запустить тесты в watch-режиме
npm run test:coverage # Запустить тесты с отчетом о покрытии
```

## Сборка для production

### Веб-версия

```bash
quasar build
```

## Особенности приложения

- **Игровая механика**: Угадайте слово за 6 попыток
- **Статистика**: Отслеживание побед, поражений и времени игры
- **Обратная связь**: Возможность отправить отзыв разработчикам
- **Кроссплатформенность**: Один код для веб и Android
- **Локальное хранение**: Статистика сохраняется в localStorage
- **Адаптивный дизайн**: Работает на разных размерах экранов

Собранные файлы будут в `dist/spa/` - их можно развернуть на любом веб-сервере.

### Android-версия

```bash
# 1. Сначала соберите веб-версию
quasar build

# 2. Скопируйте изменения в Capacitor проект
npx cap copy

# 3. Откройте проект в Android Studio
npx cap open android
```

В Android Studio вы сможете:
- Запустить приложение на эмуляторе или реальном устройстве
- Собрать APK или AAB файл для публикации в Google Play Store
- Отладить нативное поведение приложения

## Технологический стек

- **Vue 3** - JavaScript фреймворк
- **Quasar Framework** - UI компоненты и инструменты сборки
- **Pinia** - Управление состоянием

- **Vite** - Сборщик и dev-сервер
- **Vitest** - Фреймворк для тестирования
